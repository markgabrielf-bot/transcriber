Audio to text, free and offline

Runs OpenAI's Whisper inside your browser. No sign up, no limits, and your file never leaves your computer.

Drop audio or video here MP3, WAV, M4A, OGG, MP4, MOV, WEBM. Long MP3s are handled in parts.
Pick a file to start.
Timestamps appear after transcribing.

First run downloads the model once, then it is cached by your browser so next time is instant. Uses your GPU (WebGPU) when available for big speed gains; works best in Chrome or Edge. The .srt file drops straight into Premiere Pro, DaVinci Resolve, or CapCut as captions.

How it works

Is it really free?

Yes. No account, no credits, no watermark, no file size cap. The code is open source under the MIT License.

Where does my audio go?

Nowhere. The AI model downloads to your browser and transcribes on your own device. Your file is never uploaded.

Which device works best?

A laptop or desktop with Chrome or Edge. Phones work for short clips but can be slow or run out of memory on long files.

How accurate is it?

Very good for clear speech. For Taglish or noisy recordings, choose "Most accurate" and set the language instead of auto detect.

Can it handle long recordings?

Yes. Long MP3s are read and transcribed part by part, and the text appears as it goes. You can stop anytime and keep what is done. For long WAV or video files, convert to MP3 first.

Can I use it offline?

After the first run, the model is cached. You still need to open the page online, but transcribing itself runs locally.

Can I copy this tool?

Please do. Use it, host it, change it, share it. Just keep the license note in the code.
